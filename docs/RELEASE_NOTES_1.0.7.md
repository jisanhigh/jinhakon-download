# 진학ON v1.0.7 — 메뉴 정리

**2026-11-04 · Windows x64**

진학ON v1.0.6의 기능은 그대로 유지하고 화면만 간결하게 정리한 업데이트입니다.

- 왼쪽 메뉴에서 **전형 점검**을 제외했습니다.
- 구버전 합격 결과가 여러 세부전형과 겹치는 경우의 안전한 확인·이전 기능은 그대로 유지합니다.
- 필요할 때는 **관리자 설정 → 유지보수 → 전형 자료 확인**에서 점검합니다.
- 전형명 정확도 개선, 세부유형·선발유형 매핑, 학년도별 발표일 대조표·CalendarTask DB 생성 기능은 유지합니다.

기존 진학ON v1.0.6과 동일한 Go/Edge 설치 경로와 프로필을 사용합니다. 설치 전 상담·합격 결과를 백업하고 기존 프로그램을 종료한 후 설치하세요.

**Windows 설치파일의 자동 빌드와 자바스크립트 구문 검사를 실시합니다.** 실제 학교 PC에서 기존 자료 유지와 CalendarTask DB 불러오기 확인은 별도로 필요합니다.

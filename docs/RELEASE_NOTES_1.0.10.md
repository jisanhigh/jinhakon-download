# 진학ON v1.0.10 — 오늘 기준 전형 일정 달력

**2026-11-09 · Windows 64비트**

교사가 전형 일정 탭에서 오늘 날짜를 바로 확인할 수 있도록 달력 사용성을 개선했습니다.

- 전형 일정 탭을 열 때 **PC 현지 날짜 기준 오늘이 포함된 달**을 보여주며 오늘을 선택합니다.
- 대교협 파일을 다시 불러와도 가장 이른 행사 날짜로 자동 이동하지 않습니다.
- 오늘 날짜는 강조하고, 달력의 **오늘** 버튼으로 언제든 바로 돌아갈 수 있습니다.
- 달력 아래 **오늘부터 14일간의 일정**(최대 12건 미리보기)을 보여주고 날짜를 누르면 해당 일정을 확인합니다.
- 기존 면접·실기·논술·적성·1단계 발표·최종발표 및 교사가 추가한 일정은 그대로 사용합니다.
- 날짜 계산에 UTC가 아닌 사용 PC의 로컬 날짜를 사용합니다.

기존 수능최저 판정과 9월·10월 모의고사 성적 저장, 상담 기록, 전형 결과, CalendarTask DB 관련 로직은 변경하지 않았습니다.

테스트: JavaScript 구문 검사, 현지 날짜·탭 재진입·다른 날짜 이동·14일 일정 목록 자동 테스트, 기존 성적 저장 테스트 및 Windows 설치파일 자동 빌드. 학교 PC에서 실제 실행과 데이터 유지 여부는 별도 확인이 필요합니다.

기존 Go/Edge 설치 경로 및 사용자 프로필은 유지됩니다. 업데이트 전에 기존 데이터를 백업하고 프로그램을 종료하세요.

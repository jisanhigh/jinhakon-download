# 진학ON — CalendarTask 설치 및 합격 발표 DB 생성

## 설치
[CalendarTask 공식 홈페이지(한국어)](https://www.xdiarys.com/?lang=kor)에서 Windows 버전을 내려받고 설치합니다.

## 기존 일정 백업
CalendarTask를 완전히 종료한 다음, Windows 파일 탐색기 주소창에 `%appdata%\CalendarTask\Db`를 입력합니다. `calendar.db`를 별도 폴더에 복사해 보관합니다. 설치 경로를 바꾼 경우 그 설치 위치의 Db 폴더에서 찾으세요. [공식 데이터 파일 안내](https://help.xdiarys.com/?p=626).

## 진학ON에서 DB 만들기
1. 진학ON에 대교협 수시 진학관리 엑셀을 불러옵니다.
2. **합격발표 DB**에서 1단계·최종 발표일 연결 건수와 누락 목록을 확인합니다.
3. 필요하면 공식 입학처 공지에 맞게 발표일 대조표를 갱신합니다.
4. **원본 calendar.db 선택 → CalendarTask DB 생성**을 누릅니다.
5. 새 파일을 CalendarTask에서 불러오고 개인 일정이 보존됐는지 확인합니다.

표시는 날짜별로 `[1단계] 대학명, 대학명`, `[최종] 대학명, 대학명` 형식이며 해당 날짜의 대학명은 생략하지 않습니다. 날짜를 확정하지 못한 전형은 CSV로 별도 출력합니다.

## 주의사항
- 기존 DB 원본은 반드시 백업하세요.
- 반복해서 불러오면 CalendarTask 설정에 따라 중복 일정이 생길 수 있습니다.
- 진학ON은 발표일을 인터넷에서 실시간 수집하지 않습니다. 대학 입학처 공식 발표일이 우선합니다.
- 학생 자료나 원본 `.db`를 공개 저장소에 올리지 마세요.
- 새로운 설치판의 브라우저 데이터 저장 경로가 이전 설치판과 동일하다고 검증된 것은 아닙니다. 기존 진학ON의 백업을 먼저 저장하세요.

# 진학ON v1.0.8 — 모의평가·학력평가 성적 PDF 인식 보완

**2026-11-09 · Windows x64**

기존 진학ON 수시 v1.0.7에 성적일람표 PDF 인식 기능을 보완했습니다.

- 평가원 9월 모의평가: 학생별 4행(선택과목·표준점수·백분위·등급) 양식을 유지합니다.
- 전국연합 10월 학력평가: 학급별 1행(영역별 등급 열) 양식을 추가합니다.
- 성적 PDF의 등급 열 위치와 학급 번호를 분석하여 국어·수학·영어·한국사·탐구 2과목 및 선택과목을 저장합니다.
- PDF 여러 파일과 서로 다른 월의 성적을 같은 학생에게 별도로 저장합니다.
- **수능최저 판정 규칙은 변경하지 않았습니다.**
- 동명이인 또는 번호가 일치하지 않는 경우 임의 연결하지 않습니다.

제공된 8반 표본으로 **9월 15명, 10월 15명**의 성적 추출·저장을 점검했습니다. 다른 기관/연도의 모든 PDF 양식 및 이미지 스캔 PDF를 검증한 것은 아닙니다.

기존 Go/Edge 설치 경로 `%LOCALAPPDATA%\Programs\JinhakON` 및 사용자 프로필 `%LOCALAPPDATA%\JinhakON\EdgeProfile`을 유지합니다. 설치 전 상담·성적 자료를 백업하고 프로그램을 종료해 주세요.

기존 상담 기능, 대교협 Excel, 발표 일정·CalendarTask DB 기능은 변경하지 않았습니다. Windows 실환경 설치·자료 유지 검사는 별도로 필요합니다.

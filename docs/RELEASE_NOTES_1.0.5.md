# 진학ON v1.0.5 — 정식 배포

**배포일: 2026-11-04 | Windows 64비트**

기존 진학ON v1.0.3의 설치 경로와 Edge 사용자 프로필을 그대로 사용하는 **덮어쓰기 업데이트**입니다. Electron 방식의 v1.0.4와 달리 별도 프로그램을 설치하지 않습니다.

### 주요 변경 사항
- 수시 지원 대학의 **1단계·최종 합격 발표 일정**을 날짜별로 묶어 확인
- CalendarTask `.db` 생성: 해당 날짜에 해당하는 **대학명을 모두 표시**하고 전형별 중복을 합쳐 정리
- 기존 `calendar.db`를 복사해 개인 일정을 유지하는 방식 지원
- 설치판 내부에 SQLite 변환 엔진을 포함하여 외부 스크립트 다운로드에 의존하지 않도록 변경
- [CalendarTask 공식 설치 사이트](https://www.xdiarys.com/) 및 DB 백업·적용 안내 추가
- 날짜가 확인되지 않은 전형은 임의 배정하지 않고 별도 확인 목록으로 제공

### 설치 방법
1. 기존 진학ON에서 상담·성적 데이터를 백업합니다.
2. 진학ON 창을 닫고 기존 프로세스가 종료된 뒤 이 페이지의 **JinhakON_Setup_1.0.5.exe**를 실행합니다.
3. 바탕화면의 기존 **진학ON** 바로가기를 통해 실행합니다.
4. 수시진학관리 Excel을 불러오고 **합격발표 DB** 메뉴를 이용합니다.

**기존 데이터:** 기존 경로 `%LOCALAPPDATA%\JinhakON\EdgeProfile`을 삭제하지 않습니다. 실제 자료는 PC에 따라 별도로 백업·점검해야 합니다.

**주의:** v1.0.4 Electron 시험판이 별도로 설치돼 있다면 해당 버전에서 입력한 자료를 먼저 백업한 다음 제거해 주세요. 전형별 발표일은 각 대학 입학처의 공지가 최종 기준입니다. 본 설치파일은 코드서명되지 않았고, 실제 학교 PC의 전 기능 검증을 보장하지 않습니다.

이전 안정판 v1.0.3은 GitHub에 보존합니다.

# 진학ON v1.0.12 — 성적 데이터 증가 시 화면 로딩 속도 개선

**2026-11-12 · Windows 64비트 · 기존 Go/Edge 설치판**

## 변경 내용
- 상담·수능최저 관리 화면을 그릴 때 동일한 성적 라이브러리를 반복해서 읽고 파싱하는 작업을 줄였습니다.
- 한 번의 화면 갱신 내에서 성적 데이터와 시험 목록을 재사용하고, 다음 갱신 때 새로 읽도록 했습니다.
- 학생별 수능최저 판정, 시험별 성적, 상담 기록, 전형 결과, PIN 재로그인 저장/복원 방식은 변경하지 않았습니다.
- 성적 조회 캐시의 반복 읽기 방지/초기화 자동 테스트를 추가했습니다.

## 설치 및 확인
1. 기존 설치본에서 상담·성적 데이터를 백업하고 프로그램을 완전히 종료합니다.
2. `JinhakON_Setup_1.0.12.exe`를 실행하면 기존 설치 경로에 덮어씁니다.
3. 기존 9월·10월 등 시험별 성적이 모두 남아 있는지, 학생별 수능최저 판정과 전형 결과가 기존과 동일한지 확인합니다.
4. 학생과 시험이 다수 등록된 환경에서 로딩 시간을 비교해 보세요.

실제 학교 PC의 성적 데이터 규모에 따른 처리 시간은 아직 검증되지 않았습니다. 코드서명되지 않은 설치파일이며 Windows SmartScreen 안내가 나올 수 있습니다. 학생 성적 PDF·개별 상담 기록·대교협 원본 파일은 GitHub에 게시하지 않습니다.

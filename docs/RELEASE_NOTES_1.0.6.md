# 진학ON v1.0.6 — 세부전형 정확도 개선

**배포일: 2026-11-04 | Windows x64 | 기존 Go/Edge 설치판 업데이트**

## 주요 변경
- 대교협 `세부유형`을 실제 전형명으로 우선 표시합니다. 원본의 `전형명(대)`·`전형유형`도 그대로 보존합니다.
- 같은 학생이 같은 대학·모집단위에서 서로 다른 세부전형에 지원한 경우 각각 별도의 지원 건으로 관리합니다.
- 지원 건별 고유키에 학년도·대학·전형유형·전형명(대)·세부유형·모집단위를 반영했습니다.
- 기존 v1.0.5의 합격·등록 자료는 새로운 고유키로 옮길 수 있습니다. **구형 키가 여러 전형과 겹칠 경우 자동으로 하나를 결정하지 않고 '전형 점검'에서 직접 선택**하도록 합니다. 기존 데이터는 지우지 않습니다.
- 대교협 `선발유형` 열을 읽어 단계별/일괄합산 구분에 활용합니다.
- `전형 점검` 화면에서 구버전 키 중복·세부유형 누락·선발유형 누락·동일 지원 건 중복을 보여줍니다.
- 발표일 대조표를 Excel 또는 UTF-8 CSV로 가져올 수 있으며, 연도별 양식 다운로드와 학년도 불일치 검사가 추가됐습니다.

## 매년 해야 할 일
진학ON 프로그램 자체는 매년 새로 설치할 필요가 없습니다. 다만 입학처 모집요강·전형명·발표일이 바뀌므로 **새 학년도 대교협 진학관리 Excel과 공식 발표일 대조표는 매년 갱신**해야 합니다.

1. 현재 학생·상담·성적·합격 결과를 먼저 백업합니다.
2. 관리자 설정에서 대입 학년도를 변경합니다.
3. 새 학년도 대교협 수시진학관리 Excel을 불러옵니다.
4. '전형 점검'에서 세부전형과 누락 항목을 확인합니다.
5. 입학처 공식 발표일을 확인하여 '합격발표 DB' 메뉴에서 해당 연도 대조표(Excel/CSV)를 불러옵니다.
6. 필요한 경우 CalendarTask 원본 DB를 백업한 뒤 새 DB를 생성합니다.

기본 내장 발표일 대조는 **2027학년도 자료에 한정**됩니다. 이후 학년도 데이터는 자동으로 채워지지 않으며, 임의로 이전 연도 날짜를 사용하지 않습니다.

## 안전하게 설치하기
- 이전 진학ON을 종료한 뒤 v1.0.6 설치파일로 덮어쓰세요. 기존 Go/Edge 설치 경로·프로필을 유지합니다.
- **설치 전 기존 진학ON의 백업 파일을 저장해 두세요.** 기존 입력값 중 전형이 겹치는 경우 직접 확인해야 할 수 있습니다.
- 학생 이름 및 합격 결과는 브라우저 로컬 저장소에서 처리합니다. GitHub 저장소에는 학생 자료를 올리지 마세요.
- 설치파일은 코드서명되지 않았습니다. Windows 환경별 최종 동작 확인을 권장합니다.
- 새 버전의 소스·빌드는 [공식 저장소](https://github.com/jisanhigh/jinhakon-download)에 포함돼 있습니다.

## 검증
실제 2027학년도 수시진학관리 엑셀 610건을 입력해 13개 기존 충돌 그룹이 새 키에서는 구분되는지, 구버전 상태가 임의로 다른 전형에 복사되지 않는지, CSV 파싱·학년도 불일치 경고가 정상 동작하는지 확인했습니다. Windows 설치파일 자체와 CalendarTask 실제 불러오기는 추가 환경 검증이 필요합니다.

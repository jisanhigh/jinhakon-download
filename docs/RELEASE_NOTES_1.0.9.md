# 진학ON v1.0.9 — 학력평가 성적 저장 오류 보완

**2026-11-09 · Windows x64**

v1.0.8에서 10월 성적 PDF를 정상 인식하더라도 학생 연결이나 저장 과정에서 성적이 남지 않을 수 있는 문제를 보완했습니다.

- 9월 모평·10월 학평 원본 PDF 인식 기능과 기존 수능최저 판정 로직을 유지합니다.
- 학급·이름이 유일한 학생에 한하여 PDF 번호와 대교협 번호가 달라도 연결하며, 결과창에 번호 차이를 표시합니다.
- **저장 직후 브라우저 성적 라이브러리와 작업 저장소를 다시 조회**하여 실제 저장된 학생만 '저장 확인'으로 표시합니다.
- 동명이인·미연결 학생은 자동으로 다른 학생에게 연결하지 않으며, 저장 실패 시 원인을 보여줍니다.
- 9월·10월 성적을 각각 보관하고 기존 저장 성적을 보존합니다.
- 저장 공간 부족 등으로 일부만 기록되면 잘못된 성공 메시지 대신 실패 안내와 이전 상태 복원을 시도합니다.

자동 테스트: 9월 자료 유지·10월 저장 재조회·학급 번호 불일치 경고·동명이인 보호·저장 실패 복원, HTML 자바스크립트 구문 검사, Windows 설치파일 빌드.

기존 Go/Edge 진학ON 설치 경로와 사용자 프로필을 유지합니다. **업데이트 전 상담·성적 데이터를 백업**하고 진학ON 창을 완전히 종료하세요.

다른 지역·연도의 모든 학급별 PDF 형식을 검증한 것은 아니며 학교 PC에서의 실제 재실행·자료 유지 확인은 필요합니다. 학생 성적 PDF 원본은 공개 저장소에 포함하지 않았습니다.

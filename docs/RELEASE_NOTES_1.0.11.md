# 진학ON v1.0.11 — 10월 성적 재로그인 시 사라지는 문제 수정

**2026-11-09 · Windows 64비트**

## 수정 원인
PIN으로 로그인할 때 **PIN 저장 당시의 성적 라이브러리를 현재 성적 라이브러리에 덮어쓰는 오류**가 있었습니다. 예를 들어 9월 성적만 있을 때 PIN 저장을 해 두고 10월 성적 PDF를 추가하면, 업로드 직후 정상 표시돼도 재로그인 시 이전 저장본이 10월 자료를 삭제할 수 있었습니다.

## 수정
- PIN 복원은 최신 **로컬 성적 라이브러리**를 우선하여 이후 등록한 10월 성적을 보존합니다.
- PIN 작업본에만 성적이 있고 현재 로컬 라이브러리가 없을 때에만 작업본을 복원합니다.
- 오래된 작업본으로 로그인해도 기존에 의도적으로 삭제한 시험 성적을 무단으로 다시 생성하지 않습니다.
- **9월·10월 성적 자료를 함께 유지**하며, 기존 수능최저 판정 기능과 오늘 기준 전형 일정 달력은 변경하지 않았습니다.
- 별도 자동 테스트에서 9월만 있는 PIN 저장본 → 10월 성적 추가 → 재로그인 2회 → 두 달 모두 유지되는 사례를 검증합니다.

기존 버전에서 10월 자료가 이미 덮어써져 손실되었다면, 업데이트 후 **원본 10월 PDF를 한 번 다시 불러와야** 할 수 있습니다. PIN 작업본은 자동으로 수정되지는 않으며, 최신 라이브러리가 손실된 자료를 자동 복구하는 기능은 아닙니다.

기존 Go/Edge 설치 경로 및 프로필을 유지하며 설치 전 자료 백업과 프로그램 종료가 필요합니다. 실제 학교 PC에서의 동작은 별도로 확인해야 합니다. 학생 원본 성적 PDF는 GitHub에 올리지 않았습니다.

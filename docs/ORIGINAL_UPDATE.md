# 진학ON v1.0.5 기존 설치판 덮어쓰기 업데이트

이번 업데이트는 **기존 Go/Edge 방식의 진학ON을 그대로 교체**하며, 별도의 Electron 앱을 설치하지 않습니다.

- 설치 파일: `%LOCALAPPDATA%\Programs\JinhakON\JinhakON.exe` (기존과 동일)
- 사용자 데이터: `%LOCALAPPDATA%\JinhakON\EdgeProfile` (삭제하지 않음)
- 접속 주소: `http://127.0.0.1:28745/` (기존과 동일)
- 바탕화면 바로가기: `진학ON.lnk` (기존 바로가기 업데이트)
- CalendarTask DB 생성용 SQLite 엔진을 프로그램 안에 포함 (오프라인 사용 가능)

## 업데이트 순서

1. 기존 진학ON에서 **상담·성적 자료 백업**을 먼저 합니다.
2. 잘못 설치된 별도 Electron 방식 v1.0.4가 있다면 Windows 설정 → 설치된 앱에서 **v1.0.4만 제거**합니다. 해당 앱에서 입력한 자료가 있다면 먼저 백업하세요. 기존 Go 버전 및 프로필은 삭제하지 마세요.
3. 기존 진학ON 창을 모두 닫고 **2분 정도 지난 후** 설치 파일을 실행합니다. 기존 Go 프로그램은 창을 닫아도 로컬 서버가 잠시 남아 있을 수 있습니다.
4. 바탕화면의 기존 ‘진학ON’ 바로가기에서 기존 상담·성적 자료가 유지되었는지 확인합니다.
5. 합격발표 DB 메뉴에서 원본 `calendar.db`를 선택하고 DB 생성을 시험합니다. CalendarTask DB도 사용 전 백업하세요.

**안전:** 설치기는 기존 실행파일을 `.backup`으로 보존한 뒤 교체를 시도합니다. 기존 Edge 저장 프로필에는 접근하지 않습니다. 단, Windows 실환경에서 사용자 자료 연속성은 별도로 확인해 주세요.

**주의:** 새 EXE는 기존 Go 프로그램이 종료된 상태에서 설치해야 합니다. 동일한 이름의 Electron 별도 프로그램까지 자동 삭제하지는 않습니다.

# 진학ON — 지산고등학교 진학업무 관리

수시 진학상담 업무관리, 대학별 지원 현황, 수능최저 점검, 전형 일정 조회, **CalendarTask 발표 일정 DB 생성** 기능을 위한 Windows 데스크톱 앱 소스 및 빌드 저장소입니다.

## 배포 상태

- **기존 설치판 v1.0.3**은 [기존 릴리스](https://github.com/jisanhigh/jinhakon-download/releases/tag/v1.0.3)에서 계속 제공됩니다.
- **개발판 v1.0.4 / 내부 기능 v9.8.0** 소스가 추가되었습니다. Windows 설치파일은 GitHub Actions `Build Windows installer`의 성공한 실행에서 테스트용 아티팩트로 받을 수 있습니다.
- 새로운 설치파일을 실제 학교 PC에서 확인하기 전까지 정식 릴리스로 간주하지 마세요.

## 주요 기능

- 대교협 진학관리 Excel 불러오기 및 대학·전형별 지원 현황 조회
- 학생별 상담·합격 결과 및 모의고사 자료 로컬 관리
- 전형 일정 자동 집계 및 날짜 미확인 건 따로 내보내기
- CalendarTask 호환 `calendar.db` 선택 → **1단계 / 최종 발표일** 합쳐 `.db`로 다운로드
- `[1단계] 대학명, 대학명` 형식으로 **해당 날짜의 대학명 전체 표시**
- 기존 CalendarTask 개인 일정 보존을 전제로 DB 새 파일 생성, 날짜 확인 불가 항목 임의 배정 금지
- [CalendarTask 공식 설치 페이지(한국어)](https://www.xdiarys.com/?lang=kor) 및 사용 가이드 제공

## 사용 방법

1. 설치된 진학ON을 실행하고 진학관리 `.xlsx`를 불러옵니다.
2. 왼쪽 **합격발표 DB** 메뉴를 선택해 날짜별 대학을 확인합니다.
3. CalendarTask에서 사용하는 원본 `calendar.db`를 **반드시 백업**한 후 선택합니다.
4. **CalendarTask DB 생성** 버튼을 눌러 생성된 `.db`를 내려받습니다.
5. CalendarTask의 불러오기 메뉴에서 생성한 `.db`를 적용하고 개인 일정과 발표 일정이 함께 있는지 확인합니다.

자세한 내용: [DB 생성 및 설치 안내](docs/CALENDARTASK.md)

## 빌드 방법

Windows 10/11 + Node.js 22 권장. 로컬에서 `npm install` 후 `npm run dist:win`을 실행하면 `dist/JinhakON_Setup_1.0.4.exe`가 생성됩니다. GitHub Actions의 `Build Windows installer` 수동 실행도 가능합니다.

SQLite 생성 라이브러리(`sql.js`)는 빌드 때 앱 내부에 포함되므로, **설치판의 DB 생성 시 외부 CDN 연결이 필요하지 않습니다**. 빌드 단계에서는 의존성 설치에 인터넷이 필요합니다.

## 데이터 보안 및 유의사항

- **학생 이름·학번·지원 원본·성적·개인 일정 DB는 절대 GitHub에 올리지 마세요.** 이 저장소에는 개인 데이터가 포함되지 않은 프로그램 소스만 둡니다.
- 원본 `.xlsx`와 `.db`는 해당 PC에서만 처리하며, DB를 새로 저장하기 전 원본은 덮어쓰지 않습니다.
- 발표일 기본 대조 자료는 2027학년도 자료로, 입학처 공지에 따라 수정될 수 있습니다. 다른 학년도에는 날짜 대조표를 다시 입력해야 합니다.
- 설치판 v1.0.4의 앱 데이터 저장 경로가 과거 v1.0.3과 같다고 검증되지 않았습니다. 설치 전에 기존 앱의 자료를 **진학ON의 백업 기능으로 저장**하세요.
- 설치파일은 코드서명이 되지 않았습니다. 학교에서 검증한 후 배포하고, SmartScreen 경고가 나올 수 있음을 안내하세요.

## 저작권 및 지원

학교 내부 진학 업무에 사용하는 도구입니다. CalendarTask는 제3자 프로그램이며 [공식 사이트](https://www.xdiarys.com/)의 안내를 따릅니다.
